# Использование BYN Symbol Montserrat

## Веб (WOFF2)

Подключите файл из `fonts/webfonts/` через `@font-face` и задайте `font-family` в CSS. Для переменного начертания используйте ось `wght` в диапазоне, заданном в экспорте из Glyphs.

## Десктоп

- **Variable:** `fonts/variable/BYNSymbolMontserrat[wght].ttf`
- **Static:** файлы в `fonts/static/` (Thin, Regular, Black и др.)

После установки шрифта в системе используйте его в приложениях как обычное семейство `BYN Symbol` (точное PostScript-имя смотрите в экспортированных шрифтах).

## Исходник

Редактирование — в Glyphs, файл `sources/BYN symbol Montserrat.glyphs`. Экспорт перезаписывает соответствующие файлы в `fonts/`.
