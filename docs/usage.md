# Использование BYN Symbol

BYN Symbol — вспомогательный шрифт для отображения знака белорусского рубля рядом с основным шрифтом проекта.

> **Важно о текущей версии:** знак временно назначен на кириллическую заглавную букву **Б (U+0411)**. Это визуальный обходной способ, а не правильная Unicode-кодировка валютного символа. Не применяйте этот шрифт ко всему тексту: обычные буквы «Б» также превратятся в знак.

## Файлы

- Variable TTF: ../fonts/variable/BYNsymbol-VariableVF.ttf
- Variable WOFF: ../fonts/variable/BYNsymbol-VariableVF.woff
- Статические OTF и WOFF: ../fonts/static/
- Исходник Glyphs: ../sources/BYN symbol.glyphs

В статической папке доступны начертания Thin, Light, Regular, Bold и Black. Веб-формат в текущем экспорте — WOFF; WOFF2 пока не собран.

## macOS

1. Скачайте variable TTF или нужный статический OTF.
2. Откройте файл двойным щелчком и выберите установку шрифта.
3. Перезапустите приложение, если BYN Symbol не появился в списке гарнитур.
4. Вставьте кириллическую заглавную Б и примените BYN Symbol только к этому символу.

## Windows

1. Скачайте TTF или OTF.
2. Нажмите правой кнопкой мыши по файлу и выберите **Install** / **Установить**.
3. При необходимости перезапустите приложение.
4. Вставьте кириллическую заглавную Б и примените BYN Symbol только к этому символу.

## Веб

Подключите WOFF через CSS:

~~~css
@font-face {
  font-family: "BYN Symbol";
  src: url("./fonts/BYNsymbol-VariableVF.woff") format("woff");
  font-weight: 100 900;
  font-style: normal;
  font-display: swap;
}

.byn-symbol {
  font-family: "BYN Symbol", sans-serif;
  font-weight: 400;
}
~~~

Использование:

~~~html
<p>1 250 <span class="byn-symbol" aria-label="Belarusian ruble">Б</span></p>
~~~

В этом примере Б — временный слот U+0411. Не используйте его как семантическое обозначение валюты в базе данных, API или текстах, которые будут передаваться без самого шрифта.

## Unicode U+20C5

Для нового знака белорусского рубля выделен код **U+20C5 BELARUSIAN RUBLE SIGN**. Unicode Technical Committee принял его для публикации в Unicode 19.0 28 октября 2026 года. На текущий момент код ещё не входит в опубликованную версию Unicode, а шрифты и операционные системы должны отдельно добавить поддержку.

**Текущие файлы BYN Symbol пока не содержат U+20C5.** После добавления маппинга именно его следует использовать как основной символ, а U+0411 оставить только для необязательного визуального alternate.

Статус: [Unicode Pipeline](https://www.unicode.org/alloc/Pipeline.html).

## Оси и альтернативы

- **wght** — ось веса определена в variable source.
- **slnt** — ось наклона присутствует в исходнике, но наклон самого BYN-глифа ещё требует доработки и проверки.
- **CONT** — оси контраста в текущей версии нет.
- **salt / ss01** — OpenType alternate в текущей версии не реализован.

## Ограничения текущей сборки

- Нет маппинга U+20C5.
- U+0411 используется как временный слот и не должен применяться к обычной букве «Б».
- Наклон самого валютного знака не завершён.
- Нет WOFF2, SVG и PNG экспортов.

Для разработки и экспорта используйте файл sources/BYN symbol.glyphs в Glyphs.
