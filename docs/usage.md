# Как использовать BYN Symbol

BYN Symbol — вспомогательный шрифт для отображения нового знака белорусского рубля рядом с текстом, набранным привычной гарнитурой.

> **Ограничение текущей версии:** знак временно размещён на месте заглавной кириллической буквы **Б (U+0411)**. Это приём для визуального отображения, а не правильный Unicode-код валюты. Применяйте BYN Symbol только к нужному знаку; не меняйте гарнитуру всего текста.

## Где скачать файлы

- [Вариативный TTF для установки](../fonts/variable/BYNsymbol-VariableVF.ttf)
- [Вариативный WOFF для сайта](../fonts/variable/BYNsymbol-VariableVF.woff)
- [Статические OTF и WOFF](../fonts/static/)
- [Исходный файл Glyphs](../sources/BYN%20symbol.glyphs)

Сейчас доступны статические начертания **Thin, Light, Regular, Bold и Black**. Формат WOFF2 пока не подготовлен.

## Установка в macOS

1. Скачайте вариативный TTF или нужный OTF.
2. Дважды нажмите на файл и установите шрифт через приложение «Шрифты».
3. Если BYN Symbol не появился в программе, перезапустите её.
4. Напечатайте **Б**, выделите только эту букву и примените шрифт BYN Symbol.

## Установка в Windows

1. Скачайте TTF или OTF.
2. В контекстном меню файла выберите «Установить».
3. При необходимости перезапустите графический редактор или офисную программу.
4. Выделите заглавную **Б** и назначьте ей BYN Symbol.

## Использование в Figma и печатных макетах

Наберите цену основным шрифтом. Вместо буквенного обозначения валюты временно поставьте **Б**. Выделите только эту букву и смените её шрифт на BYN Symbol.

Перед передачей макета в печать проверьте наличие и встраивание шрифта либо переведите знак в кривые средствами используемой программы. При работе с редактируемыми документами убедитесь, что получателю доступен шрифт.

## Подключение на сайте

Поместите файл WOFF в папку шрифтов веб-проекта и объявите гарнитуру:

~~~css
@font-face {
  font-family: "BYN Symbol";
  src: url("./fonts/BYNsymbol-VariableVF.woff") format("woff");
  font-weight: 100 900;
  font-style: normal;
  font-display: swap;
}

.byn-symbol {
  font-family: "BYN Symbol", sans-serif;
  font-weight: 400;
}
~~~

Используйте отдельный элемент только для знака:

~~~html
<p>1 250 <span class="byn-symbol" aria-label="Белорусский рубль">Б</span></p>
~~~

Указанный путь к WOFF — пример: скорректируйте его под структуру вашего сайта. Внутри элемента **Б** обозначает временный слот U+0411. Для доступности текста предусмотрена подпись aria-label, но такой подход всё равно не заменяет корректную Unicode-кодировку.

**Не сохраняйте «Б» в исходных данных как идентификатор валюты.** Для финансовых операций, обмена данными и баз данных используйте буквенный код **BYN**.

## Как работает вариативность

- **wght** — изменение толщины штриха. Ось присутствует в исходнике шрифта.
- **slnt** — наклон. Ось присутствует, но наклон самого валютного глифа требует доработки и проверки.
- **CONT** — контраст вертикальных и горизонтальных штрихов. Пока не реализован.
- **salt / ss01** — альтернативные глифы OpenType. Пока не реализованы.

Не следует предполагать, что все запланированные оси уже корректно работают в опубликованном файле.

## Когда появится полноценный символ

Для белорусского рубля принят к будущей публикации код **U+20C5** с официальным именем **BELARUSIAN RUBLE SIGN**. Он предусмотрен для Unicode 19.0, который по состоянию на ноябрь 2026 года ещё не опубликован.

В текущем экспорте **U+20C5 отсутствует**. После его реализации именно этот код нужно будет использовать вместо временной Б.

[Проверить статус в плане Unicode](https://www.unicode.org/alloc/Pipeline.html).

## Известные ограничения

- Нет полноценной Unicode-кодировки U+20C5 в готовых файлах.
- Временная замена через Б подходит только для визуального отображения.
- Наклон валютного глифа ещё не доведён до готового результата.
- Нет оси контраста, альтернативного OpenType-глифа и форматов WOFF2, SVG и PNG.

Редактируемый исходник находится в [файле Glyphs](../sources/BYN%20symbol.glyphs).
