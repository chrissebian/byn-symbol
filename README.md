# BYN Symbol (Montserrat)

Набор глифов и шрифтового семейства для символа белорусского рубля 2026 (BYN) на базе Montserrat.

## Структура

- `sources/` — исходник Glyphs (`BYN symbol Montserrat.glyphs`).
- `fonts/variable/` — переменный TTF.
- `fonts/static/` — статические OTF и WOFF2 для веба
- `docs/` — документация по использованию.
- `tests/` — проверка отрисовки в браузере.
